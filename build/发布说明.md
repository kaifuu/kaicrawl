# KaiCrawl 发布说明（EXE 打包 / Win7 部署）

## 一、本机如何打出 EXE

### 前提（仅构建机需要，Win7 目标机什么都不用装）
- 安装 **Python 3.8.10**（Win7 支持的最后主线版本）：
  https://www.python.org/downloads/release/python-3810/ 下载 `Windows x86-64 executable installer`
  （若目标 Win7 是 32 位系统，请装 3.8.10 的 x86 版，打包出来的 EXE 才是 32 位）
- 不想装到默认位置也行，装好后记住 `python.exe` 路径，打包时用
  `python build_exe.py --python "D:\Python38\python.exe"` 指定，
  或设环境变量 `KAI_WIN7_PYTHON` 指向它。

### 打包命令（在项目根目录）
```
python build_exe.py --channel win10     # Win10 正式包：当前 Python + 内置浏览器渲染（推荐）
python build_exe.py                     # --channel win7：自动寻找 3.8/3.9 → 独立环境 → 锁定依赖
```
> 也可以不走命令行：登录网页端 → 左侧菜单「📦 发布管理」→「新建发布」，
> 选渠道、填版本号/启动端口/更新说明即可，构建日志实时滚动，产物 zip 可直接下载，版本历史全程留档。

渠道说明：
| 渠道 | 工具链 | 浏览器渲染 | 适用系统 |
| --- | --- | --- | --- |
| `win10`（默认推荐） | 当前 Python + PyInstaller 6 | ✅ 内置 Playwright + Chromium（产物约 200MB，EXE 旁 `ms-playwright\`） | Win10 及以上 |
| `win7` | Python 3.8/3.9 独立环境 + PyInstaller 5 | ❌（Chromium 110+ 不支持 Win7） | Win7 及以上 |
| `smoke` | 当前 Python | ❌ | 仅验证打包链路，别对外发 |

参数：
- `--channel win7|win10|smoke` 选渠道（不填默认 win7；旧写法 `--smoke` 仍兼容）
- `--port 端口` 打包版启动端口（写入产物 PORT.txt，不填用默认 5000）
- `--python 路径` 指定 Win7 版 Python
- `--fast` 依赖已装过，跳过安装直接打包（改了代码只重新打包时用）

产物：**`dist\KaiCrawl\`**（绿色目录版，整个文件夹拷走即可用），入口 `KaiCrawl.exe`。

### 可选：做成单文件安装程序
1. 装 Inno Setup 6：https://jrsoftware.org/isdl.php
2. 双击 `build\KaiCrawl.iss` → 菜单 Build → Compile
3. 得到 `dist\KaiCrawl_Setup.exe`（普通用户权限即可安装，装到
   `C:\Users\当前用户\AppData\Local\KaiCrawl`，不用管理员，避开 Program Files 写权限问题）

## 二、Win7 电脑上安装运行

- 绿色目录版：把 `dist\KaiCrawl` 整个文件夹拷到目标机任意**可写**目录（如 `D:\KaiCrawl`），
  双击 `KaiCrawl.exe`，等 1~2 秒会自动弹出浏览器打开 `http://127.0.0.1:5000`。
  （没自动弹就在浏览器手动输该地址；黑控制台窗口别关，关了程序就停了。）
- 安装包版：双击 `KaiCrawl_Setup.exe` 一路下一步，桌面出快捷方式。
- 首次启动会自动在 EXE 旁创建 `data\crawler.db` 并从内置 Excel 种子导入数据源；
  登录账号 `admin` / `admin123`。

## 三、Win7 环境注意事项

| 事项 | 说明 |
| --- | --- |
| 数据存放 | 全部在 **EXE 同目录** 的 `data\`（数据库 crawler.db、文档输出 output\、日志）。换电脑 = 拷整个文件夹。卸载安装包版默认**保留** data，删数据请手动 |
| 浏览器渲染 | **Win10 包内置** Playwright + Chromium（EXE 旁 `ms-playwright\`，随包走、免安装），渲染模式开箱即用；万一内置浏览器被杀软误删，自动回退驱动系统 Chrome。**Win7 包无渲染组件**（Chromium 110+ 不支持 Win7），相关源请改 static 模式或「手动导入 / URL 批量导入」 |
| 端口 | 默认 `127.0.0.1:5000`；发布管理构建时可指定启动端口（写入 EXE 旁 `PORT.txt`）。部署后想换端口：用记事本改 `PORT.txt` 里的数字存盘重启即可，无需重打包。被占用启动会报错，关掉占端口的程序再开 |
| 杀毒软件 | PyInstaller 程序偶被误报。本包已关 UPX 压缩降低误报率；仍被拦请在杀软里加白名单 |
| 防火墙 | 只监听本机 127.0.0.1，一般不会弹防火墙；若局域网访问需自行改 config 后重新打包 |
| 升级 | 覆盖 EXE 所在目录里除 `data\` 外的所有文件即可，数据不丢 |

## 四、发布产物清单

```
build_exe.py            打包编排脚本（入口）
requirements-win7.txt   Win7 兼容依赖锁定（全部验证过 3.8 可装）
build\KaiCrawl.spec     PyInstaller 配置（onedir、剔除 playwright/tkinter、不压缩）
build\KaiCrawl.iss      Inno Setup 安装包脚本（可选）
build\发布说明.md        本文档
```
